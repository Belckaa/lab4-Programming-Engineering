# Специфікація вимог до програмного забезпечення (SRS)

## Назва проєкту
**TaskFlow – система управління завданнями**

## 1. Вступ
**Мета:**  
Розробити веб-застосунок для організації особистих та командних завдань.

**Цільова аудиторія:**  
Користувачі, які працюють над проєктами в командах, фрілансери, менеджери.

**Область застосування:**  
Веб-платформа для відстеження прогресу, призначення задач і комунікації.

## 2. Загальний опис
- Веб-інтерфейс з авторизацією
- Підтримка кількох мов (українська, англійська)
- Сучасний дизайн (адаптивний)
- REST API для інтеграцій

## 3. Функціональні вимоги
- Реєстрація та авторизація користувача
- Створення, редагування, видалення задач
- Призначення задачі іншому користувачу
- Сортування задач за пріоритетом та терміном
- Коментарі до задач
- Відстеження історії змін

## 4. Нефункціональні вимоги
- Висока доступність (99.9%)
- Час відповіді сервера – не більше 1 секунди
- Підтримка 1000+ одночасних користувачів
- Захист даних (шифрування, HTTPS)
- Масштабованість на майбутнє

## 5. Обмеження
- Працює лише в сучасних браузерах
- Необхідне з'єднання з інтернетом
- База даних – PostgreSQL або подібна
